## 当前原型

- 在线原型：https://ft710-touch-controller.xun-ke-7448.chatgpt.site
- 当前范围：频率直接输入、功率调节、DNR、模式选择、波段选择。
- 明确约束：模式与波段按钮不做界面联动；初代不提供 PTT。
- 项目完整规划、设计、试验、开发、纠错、最终实现过程及图片归档见 [[16_项目完整过程总记录]]；首轮实机反馈照片已补充归档。

## 当前硬件/环境进展

- 开发路线已确定为 VSCode + ESP-IDF，不使用 Arduino 作为项目主线。
- 本机 ESP-IDF v5.5.5 环境已修复并验证可用。
- 微雪 `08_lvgl_display_panel` 示例已在 ESP32-P4 实机上完成构建、烧写和启动日志验证。
- 实测开发板芯片为 ESP32-P4 rev v1.3，示例已调整为 v1.x 芯片配置。
- FT-710 直连本电脑后，`COM5 Enhanced COM Port` CAT 通信已验证正常；USB 接收音频到电脑扬声器监听正常。
- FT-710 接到 ESP32-P4 后，ESP 端能识别到 USB Hub，但 ESP-IDF v5.5.5 当前不支持 HS Hub 下游 FS 设备所需的 TT，暂未枚举到 CP2105 CAT 串口。
- 已尝试 ESP32-P4 OTG1.1 Full-Speed 根口 workaround，仍无法完成 FT-710 USB 枚举；当前推荐改走 FT-710 CAT-3 TTL UART。
- 已按 JI1FGX Yaesu CP2105 ESP32-S3 项目思路移植本地 USB Hub 组件并绕过 TT 检查，实机仍失败于 `CHECK_SHORT_DEV_DESC`；详见 [[11_JI1FGX_CP2105方案移植尝试记录]]。
- 外置 CH9102 USB-TTL 接 FT-710 CAT-3 后，ESP32-P4 USB Host 已成功完成 CAT 最小闭环，`ID; FA; FB; MD0; MD1;` 全部返回完整响应；详见 [[12_ESP32P4_CH9102_USBTTL_CAT3实测记录]]。
- 外置 CH9102 + CAT-3 链路已进一步完成写入控制与 UI 实测：VFO-A/VFO-B 频率写入、模式写入、DNR 开关和等级设置均可用；最小 LVGL 界面已实现双 VFO 频率显示和触摸数字键盘，`100 ms` 轮询可接受；详见 [[13_ESP32P4_CH9102写入控制与最小UI实测记录]]。
- 已建立正式工程 `D:\CAT CONTROL\ft710_controller`，实现 1024 × 600 横屏正式控制界面，并在 ESP32-P4 实机上完成 build、flash、启动、CH9102 CAT 连接和首轮 UI/响应速度修正；详见 [[14_正式控制界面实现与首轮实机修正记录]]。
- 已实现 WiFi 设置页：状态栏 WiFi 按钮进入、左侧可滚动扫描列表、右侧 SSID/IP/Gateway/DNS/状态显示、SSID/Password 输入框、连接/断开按钮、SNTP 时间显示和本地/UTC 切换；WiFi 界面从复杂设置面板收敛为 STA 路由器连接页的设计过程、时间显示设计过程、软键盘 `CLEAR/BACK/SPACE` 修正均已记录；详见 [[15_WiFi设置界面与软键盘修正记录]]。
- 2026-08-28 启动新阶段：使用 ESP32-DevKitC-32E 作为 CAT-3 到 BLE 的无线桥接端。DevKitC 已在 COM8 识别为 ESP32-D0WD-V3，WiFi scan 实测成功，BLE UART 广播/连接/写入/notify 回显实测成功；详见 [[18_ESP32DevKitC32E_BLE_CAT3桥接前置测试记录]]。
- 2026-08-29 完成 ESP32-P4 + MCP23017 + EC11 外接旋钮最小闭环测试：MCP23017 通过 I2C 自动识别为 `0x27`，频率旋钮 A/B/S 接 PA0/PA1/PA2，功率旋钮 A/B/S 接 PA6/PA7/PB0；频率旋钮可改变输入并按键确认发送 `FA...;`，功率旋钮可按 1W 步进发送 `PCxxx;`；同次修正模式按钮目标，使其跟随输入目标 A/B 发送 `MD0x;` 或 `MD1x;`；详见 [[19_MCP23017_EC11外接旋钮频率输入测试]]。
- 2026-08-29 完成 0.96 寸 SSD1306 OLED 独立测试与 Qwiic Mux 联动测试：OLED 直连阶段确认 ESP32-P4 需使用 `I2C1/SDA GPIO7/SCL GPIO8`；加入 TCA9548A 后，Mux 地址 `0x70`、OLED channel `3`、OLED 地址 `0x3C`、MCP23017 地址 `0x27` 均实测正常；旋转 RF Power EC11 时 OLED 可大字实时显示功率数值变化；详见 [[20_096寸SSD1306_OLED与TCA9548A功率旋钮显示测试]]。
