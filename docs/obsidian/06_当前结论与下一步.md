# 当前结论与下一步

## 已确定的技术方向

- 主控板：Waveshare ESP32-P4-WIFI6-LCD-TOUCH-7B。
- 主处理器：ESP32-P4，负责 UI、触摸、USB Host、CAT 和状态机。
- 无线：板载 ESP32-C6，作为 Wi-Fi 6 / BLE 协处理器。
- 显示：7 英寸 1024 × 600 MIPI-DSI。
- 触摸：GT911 电容触摸。
- GUI：ESP-IDF + LVGL 9。
- 电台连接：当前第一阶段可行链路为 FT-710 CAT-3 TTL UART，经外置 CH9102 USB-TTL 接入 ESP32-P4 USB Host；FT-710 USB Enhanced/CP2105 直连保留为后续研究路线。
- USB 串口：当前已验证 CH9102 `VID:PID 1A86:55D4` 可通过 `usb_host_cdc_acm` 打开；CP210x VCP Host 受 FT-710 内置 Hub/TT 限制暂不作为第一阶段主线。
- 初代功能：频率、功率、DNR、模式、波段。
- 安全约束：不实现 PTT。
- 交互约束：模式与波段在界面层互不联动。
- 开发路线：VSCode + ESP-IDF，不使用 Arduino 作为主线。
- 当前固定环境：ESP-IDF v5.5.5，Target `esp32p4`。
- 实测开发板芯片：ESP32-P4 rev v1.3，MAC `e8:f6:0a:e3:59:c6`，下载/日志串口 `COM4`。
- FT-710 电脑直连 CAT 基准：`COM5 Enhanced COM Port`，38400、8N2、无流控，`ID; -> ID0800;`。
- FT-710 电脑直连 USB Audio 基准：Windows 可获取 `USB Audio Device` 输入，并播放到电脑扬声器。
- ESP32-P4 直连 FT-710 USB 当前结论：ESP 能看到 FT-710 USB 路径中的 Hub，但 ESP-IDF v5.5.5 USB Host Hub 栈不支持 High-Speed Hub 下游 Full-Speed 设备所需的 TT，因此暂未枚举到 CP2105 CAT 串口。
- 已尝试强制 ESP32-P4 OTG1.1 Full-Speed 根口和根口 power-cycle workaround，仍无法完成 FT-710 USB 枚举。
- 已按 JI1FGX Yaesu CP2105 ESP32-S3 项目思路建立 `D:\CAT CONTROL\ft710_ji1fgx_probe`，移植本地 `espressif__usb` 组件并绕过 TT 检查；实机日志出现 `Trial:`，但随后失败于 `CHECK_SHORT_DEV_DESC`，确认单纯放行 Hub 检查不足以枚举 FT-710 下游 CP2105。
- 当前推荐解决路线：第一阶段采用 FT-710 后面板 CAT-3，经外置 CH9102 USB-TTL 接入 ESP32-P4 USB Host；已完成 ESP 实机 CAT 读取、写入和最小触摸 UI 闭环。

## 下一轮开发建议

1. 补拍/记录 `08_lvgl_display_panel` 的红/绿/蓝/白画面和触摸黑色轨迹，完成 P1 人工观察证据。
2. 将 `D:\CAT CONTROL\ft710_ch9102_usb_probe` 与 `08_lvgl_display_panel` 中验证通过的 CH9102 USB Host CAT 代码整理为正式 `CatTransport`。
3. 将当前临时 UI/CAT 混合代码拆分为 `ui`、`radio_state`、`cat_transport`、`command_queue`。
4. 在 ESP32-P4 上扩展 `ID; FA; FB; MD0; MD1; PC; NR0; RL0;` 等状态轮询，并完成分号拆帧、超时、错误分类和回读确认。
5. 基于当前已验证的双 VFO 显示和数字键盘，继续加入模式、DNR、功率等第一阶段控制。
6. 针对外置 CH9102 + CAT-3 做热插拔、开关电台、长稳和射频环境抗扰测试。
7. 单独复测 `FA007074000;` 回读偏 `700 Hz` 的现象，确认与模式、RIT/CLAR、步进或测试过程的关系。
8. 保留 CP2105 Enhanced/FT-710 后 USB 直连作为未来 ESP-IDF 支持 Hub TT 后的可选方案。
