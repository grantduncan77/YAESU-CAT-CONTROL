## 6. 芯片版本问题与修复

第一次构建成功后，烧写失败。失败原因不是环境问题，而是示例默认配置要求芯片最小版本为 ESP32-P4 rev v3.0，但当前开发板实际芯片为 rev v1.3。

失败信息：

```text
bootloader/bootloader.bin requires chip revision in range [v3.0 - v3.99]
this chip is revision v1.3
Use --force to flash anyway
```

处理原则：

- 没有使用 `--force` 强制烧写。
- 改为修正 `sdkconfig.defaults`，让 bootloader 和应用按实际芯片版本重新构建。

已修改：

```text
D:\CAT CONTROL\ESP32-P4-WIFI6-Touch-LCD-7B-main\examples\esp-idf\08_lvgl_display_panel\sdkconfig.defaults
```

关键配置：

```text
CONFIG_IDF_TARGET="esp32p4"
CONFIG_ESP32P4_SELECTS_REV_LESS_V3=y
CONFIG_ESP32P4_REV_MIN_100=y
```

修复后执行：

```powershell
. 'D:\CAT CONTROL\idf-v5.5.5.ps1'
idf.py fullclean
idf.py set-target esp32p4
idf.py build
```

重新构建日志中可见使用 v1.x 对应的 ESP32-P4 ROM 链接脚本，说明修复生效。
