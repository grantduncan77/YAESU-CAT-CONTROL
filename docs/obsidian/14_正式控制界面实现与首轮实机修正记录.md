# 正式控制界面实现与首轮实机修正记录

## 背景

在 [[13_ESP32P4_CH9102写入控制与最小UI实测记录]] 中，已经验证 ESP32-P4 可以通过外置 CH9102 USB-TTL 连接 FT-710 CAT-3，并完成读取、写入和最小触摸 UI 闭环。

本阶段从“测试 UI”进入“正式控制界面第一版”：

- 不再继续把 `08_lvgl_display_panel` 示例作为主线。
- 建立正式工程 `D:\CAT CONTROL\ft710_controller`。
- 按最终横屏原型实现实际 LVGL 控制界面。
- 接入 CH9102 + CAT-3 通信。
- 烧写实机并根据实机照片修正首轮问题。

## 频率显示区

显示双 VFO：

```text
VFO-A xx.xxx.xxx  MODE / POWER
VFO-B xx.xxx.xxx  MODE / POWER
```

实机照片中示例：

```text
VFO-A 50.125.000  DATA-U 100W
VFO-B 11.735.000  AM     100W
```

当前工作 VFO 通过标签颜色突出。功率来自 FT-710 `PC;` 全局回读，因此 VFO-A/VFO-B 右侧功率当前显示相同。

## 数字键盘功能

按键布局：

```text
1 2 3
4 5 6
7 8 9
. 0 BS
A B A/B
CLR ENTER / SET
```

功能：

- `0-9`：输入频率。
- `.`：输入 MHz 小数点。
- `BS`：删除一位。
- `CLR`：清空输入。
- `A`：输入目标设为 VFO-A。
- `B`：输入目标设为 VFO-B。
- `A/B`：切换 FT-710 当前工作 VFO，不交换频率。
- `ENTER / SET`：把输入频率写入目标 VFO。

频率输入解析：

- 用户输入以 MHz 处理，如 `14.270`。
- 固件转换为 Hz。
- CAT 发送为 9 位 Hz。

示例：

```text
FA014270000;
FB021400000;
```

## RF Power 功能

界面：

```text
2W 5W 10W
当前功率，例如 100W
- +
```

定义：

- `2W / 5W / 10W` 是功率调整步进，不是直接功率值。
- `+ / -` 按当前步进调整功率。
- 目标值钳位在 `5..100 W`。
- 发送 `PCxxx;`。

实测日志示例：

```text
PC023;
PC025;
PC015;
PC005;
```

## DNR 功能

界面：

```text
DNR
RLxxx
-   OFF / 01..15   +
DNR LEVEL
```

逻辑：

- `D+`：关闭状态下从 Level 1 开始；开启状态下等级加一。
- `D-`：等级减一；减到 0 时关闭 DNR。
- 等级钳位在 `0..15`。

CAT 命令：

```text
NR00;     关闭 DNR
RL0xx;    设置 DNR 等级
NR01;     打开 DNR
```

例如：

```text
RL007;
NR01;
```

## Mode 功能

界面：

```text
LSB
USB
FM
AM
DATA-U
```

逻辑：

- 对当前工作 VFO 写入模式。
- VFO-A 使用 `MD0x;`。
- VFO-B 使用 `MD1x;`。

示例：

```text
MD01;   VFO-A LSB
MD02;   VFO-A USB
MD05;   VFO-A AM
MD1C;   VFO-B DATA-U
```

本阶段修正了 DATA-U 回读解析，使 `MD0C;`、`MD1C;` 也能被识别。

## Band 功能

界面：

```text
3.5  7  14
21   28 50
```

逻辑：

- 对当前工作 VFO 直接写默认频率。
- 不调用 FT-710 Band Stack 记忆。
- 避免 Band Stack 连带切换模式，符合“模式与波段在界面层不联动”的约束。

默认频率：

```text
3.5 -> 3.500000 MHz
7   -> 7.074000 MHz
14  -> 14.270000 MHz
21  -> 21.400000 MHz
28  -> 28.400000 MHz
50  -> 50.125000 MHz
```

## CAT 队列设计

为避免 LVGL 触摸事件和后台轮询同时操作 CH9102 句柄，采用命令队列：

```text
LVGL touch event
  -> app_cmd_t queue
  -> cat_task
  -> cdc_acm_host_data_tx_blocking()
```

后台读取也在 `cat_task` 中完成。

优点：

- UI 线程不直接阻塞在串口 IO。
- 避免多个任务同时读写同一个 CDC ACM 句柄。
- 触摸写入与轮询回读统一串行化。

## CH9102 打开流程

正式固件使用已验证的 CDC ACM Host 路线：

1. `usb_host_install()`
2. 启动 `usb_lib_task`
3. `cdc_acm_host_install(NULL)`
4. `cdc_acm_host_open(0x1A86, 0x55D4, 0, ...)`
5. 设置 line coding 为 `38400 8N1`
6. 设置 RTS/DTR 为无效状态

启动日志目标：

```text
Waiting for CH9102 1A86:55D4
CH9102 opened, FT-710 control UI running
```

## 轮询策略

第一版如果把所有状态平均轮询：

```text
ID;
FA;
FB;
MD0;
MD1;
PC;
NR0;
RL0;
VS;
```

会导致频率刷新被拖慢。

修正策略：

```text
每轮:
  FA;
  FB;

每 3 轮:
  轮询一个慢状态:
    ID;
    MD0;
    MD1;
    PC;
    NR0;
    RL0;
    VS;

轮间 delay:
  70 ms
```

这样保证双 VFO 频率优先刷新，其他状态慢速校准。

## 第一轮编译问题

### 未使用变量导致失败

报错：

```text
error: 'C_WARN' defined but not used [-Werror=unused-const-variable=]
error: 'C_PANEL_2' defined but not used [-Werror=unused-const-variable=]
```

修正：

- 删除未使用的 `C_WARN`。
- 删除未使用的 `C_PANEL_2`。

### `atoi()` 头文件

使用 `atoi()` 解析功率步进，因此补充：

```c
#include <stdlib.h>
```

### DATA-U 模式解析

原模式解析只支持数字，不能解析 `MD0C;`。

修正：

- 支持 `0..9`
- 支持 `A..F`
- 使用 `toupper()`

### DNR 关闭日志为空

原先关闭 DNR 直接发送字符串常量：

```c
cat_send(dev, "NR00;", ...)
```

但日志打印 `out` 缓冲，导致：

```text
CAT set  -> ESP_OK
```

修正为先填充 `out`：

```c
snprintf(out, sizeof(out), "NR00;");
err = cat_send(dev, out, &elapsed_ms);
```

## 布局修正

### 数字键盘重叠

原参数：

```c
const int kx = 22, ky = 264, kw = 116, kh = 54, gap = 8;
button(scr, "CLR", "CLR", 22, 574 - 48, 178, 48, ...);
button(scr, "ENTER / SET", "SET", 208, 574 - 48, 176, 48, ...);
```

问题：

- 5 行键盘高度为 `5 * 54 + 4 * 8 = 302 px`。
- 从 `y=264` 开始，底部接近 `566`。
- `CLR / ENTER` 从 `526` 开始，发生重叠。

修正：

```c
const int kx = 22, ky = 258, kw = 116, kh = 46, gap = 7;
button(scr, "CLR", "CLR", 22, 540, 178, 44, ...);
button(scr, "ENTER / SET", "SET", 208, 540, 176, 44, ...);
```

效果：

- 单键高度从 `54` 降到 `46`。
- 行距从 `8` 降到 `7`。
- 第 5 行底部约 `534`。
- `CLR / ENTER` 从 `540` 开始，避免覆盖。

### DNR OFF 字体

原参数：

```c
s_dnr_label = label(scr, "OFF", 844, 162, &lv_font_montserrat_48, C_CYAN);
label(scr, "DNR LEVEL", 834, 230, &lv_font_montserrat_14, C_MUTED);
```

修正：

```c
s_dnr_label = label(scr, "OFF", 822, 168, &lv_font_montserrat_40, C_CYAN);
label(scr, "DNR LEVEL", 826, 232, &lv_font_montserrat_14, C_MUTED);
```

效果：

- `OFF` 字号从 48 降到 40。
- 位置左移并略下移。
- 减少右侧溢出。

## 功率和 DNR 响应速度修正

### 原问题

第一版点击 `P+ / P-` 后：

- UI 只入队相对调整命令。
- CAT task 根据旧状态发送命令。
- 屏幕等待慢轮询 `PC;` 回读后才更新。

因此触摸后界面数字不马上变化，尤其功率控制主观反应慢。

### 新策略：本地乐观更新 + 回读校准

修正后：

1. 触摸事件中立即计算目标值。
2. 立即写入 `s_state`。
3. 立即刷新 LVGL。
4. 同时将明确目标命令入队到 CAT task。
5. 后台轮询继续读取 FT-710，最终以电台回读校准。

这样让界面手感变快，同时不放弃真实回读。

### 功率修正

修正前：

```c
cmd.type = CMD_ADJUST_POWER;
cmd.delta = strcmp(id, "P+") == 0 ? 1 : -1;
send_cmd(&cmd);
```

修正后：

```c
int p = (int)s_state.power_w + (strcmp(id, "P+") == 0 ? (int)s_power_step : -(int)s_power_step);
if (p < 5) p = 5;
if (p > 100) p = 100;
s_state.power_w = (uint8_t)p;
cmd.type = CMD_SET_POWER;
cmd.value = (uint8_t)p;
send_cmd(&cmd);
```

效果：

- 点击后屏幕立即显示目标功率。
- CAT 层发送明确目标 `PCxxx;`。
- 不再依赖慢轮询后才更新界面。

### DNR 修正

修正后逻辑：

```c
int level = s_state.dnr_on ? s_state.dnr_level : 0;
level += strcmp(id, "D+") == 0 ? 1 : -1;
if (level <= 0) {
    level = 0;
    s_state.dnr_on = false;
} else {
    if (level > 15) level = 15;
    s_state.dnr_on = true;
}
s_state.dnr_level = (uint8_t)level;
cmd.type = CMD_SET_DNR_LEVEL;
cmd.value = (uint8_t)level;
send_cmd(&cmd);
```

新增 `CMD_SET_DNR_LEVEL` 处理：

```c
if (cmd->value == 0) {
    snprintf(out, sizeof(out), "NR00;");
    err = cat_send(dev, out, &elapsed_ms);
} else {
    uint8_t level = cmd->value > 15 ? 15 : cmd->value;
    snprintf(out, sizeof(out), "RL0%02u;", level);
    err = cat_send(dev, out, &elapsed_ms);
    if (err == ESP_OK) {
        vTaskDelay(pdMS_TO_TICKS(20));
        err = cat_send(dev, "NR01;", &elapsed_ms);
    }
}
```

变化：

- DNR 关闭发送 `NR00;`。
- DNR 开启或调级发送 `RL0xx;` + `NR01;`。
- `RL` 到 `NR01` 的延迟从 40 ms 降到 20 ms。
