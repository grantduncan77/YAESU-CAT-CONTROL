## 助手可见回复与交付内容归档

以下按阶段记录助手在当前对话中可见的回复、执行动作和交付结果。

### 1. Obsidian 与开发资料读取

- 读取并确认正确 Obsidian vault 路径为 `D:\OBSIDIAN\GPT CODING\CAT Control`。
- 区分了 Obsidian 项目资料和 ESP32-P4 设备开发文档、工具、示例资料。
- 建立了项目知识库索引与后续文档结构。

### 2. ESP-IDF / VSCode 环境修复

- 检查 ESP-IDF 环境。
- 修复 ESP-IDF v5.5.5 开发环境。
- 确认 VSCode + ESP-IDF 路线可行。
- 不采用 Arduino 作为正式项目主线。
- 构建、烧写并运行 Waveshare `08_lvgl_display_panel` 示例。
- 纠正 ESP32-P4 revision 配置与实机不匹配的问题。
- 记录 LCD、触摸、PSRAM、LVGL task 启动日志。

### 3. FT-710 电脑侧 CAT 与 USB Audio 测试

- 使用电脑直连 FT-710 USB，测试 Enhanced COM Port。
- 验证 `ID; -> ID0800;`。
- 设置 VFO-A 为 `14.270000 MHz`。
- 设置 VFO-B 为 `21.400000 MHz`。
- 设置 VFO-A / VFO-B 为 USB。
- 打开 DNR 并设置等级。
- 读取 DNR 状态。
- 获取 FT-710 USB Audio 并在电脑扬声器播放。
- 用户确认监听正常。
- 将测试过程写入 Obsidian。

### 4. ESP32-P4 直连 FT-710 USB Host 尝试

- 建立 `ft710_usb_probe`。
- 启用 USB Host Hub 支持。
- 尝试枚举 FT-710 后 USB 路径中的 Hub 和 CP2105。
- 发现 ESP-IDF v5.5.5 下 Hub/TT 限制导致无法枚举下游 CP2105。
- 回答用户关于 CP210x 官方驱动、IDF 5.5.4 Hub attach bug、P4 USB Host 通道数和 OTG 可行性的询问。
- 查询并分析 ESP32 控制 Yaesu 电台的相关开源思路。

### 5. JI1FGX / CP2105 / Hub 方案尝试

- 分析 Yaesu CP2105 ESP32-S3 项目的 Hub/CP2105 方案。
- 建立 `ft710_ji1fgx_probe`。
- 移植并保留本地修改过的 `espressif__usb` 组件。
- 尝试绕过 TT 检查。
- 实机仍失败于 `CHECK_SHORT_DEV_DESC`。
- 形成结论：该路线暂不作为第一阶段主线。

### 6. CH9102 + CAT-3 路线验证

- 根据用户将 CAT-3 接到电脑和 ESP32-P4 的硬件动作，测试 CH9102 USB-TTL 链路。
- 确认 CAT-3 参数为 `38400 8N1`。
- 建立 `ft710_ch9102_usb_probe`。
- ESP32-P4 USB Host 成功打开 CH9102 `VID:PID 1A86:55D4`。
- 读取 FT-710 `ID/FA/FB/MD0/MD1` 等状态。
- 写入 VFO-A/VFO-B 频率、模式、DNR 开关、DNR level。
- 记录到 Obsidian。

### 7. 最小 UI 与轮询验证

- 根据用户要求先做最小显示界面。
- 验证 VFO-A/VFO-B 双频率显示。
- 确认约 `100 ms` 轮询可接受。
- 加入数字键盘修改频率。
- 验证频率写入后可通过回读确认。
- 将测试过程尽可能详细记录到 Obsidian。

### 8. 正式主控制界面实现

- 读取 Obsidian 中原型设计和功能要求。
- 展示并依据用户反馈调整原型：
  - 横屏。
  - 频率输入区缩小到约 40%。
  - VFO-A/VFO-B 上下显示。
  - 顶部状态栏。
  - DNR `+/-` 加大。
  - 功率单位 `W` 与数字同行。
  - Band 数字加大。
  - 模式/功率字体加大。
- 在 `ft710_controller` 中实现正式 1024 x 600 LVGL 控制界面。
- 实现 CAT 状态、双 VFO、数字键盘、Mode、Band、RF Power、DNR。
- 根据实机照片修正键盘重叠、DNR OFF 过大、功率/DNR 响应慢。
- 使用本地乐观更新和后续回读校准。

### 9. WiFi 页面、时间显示和软键盘

- 生成 WiFi 配置界面设计图。
- 根据用户反馈修正越界和重叠。
- 将 WiFi 需求从复杂设置页面收敛为 STA 路由器连接页面。
- 说明目标板 WiFi 路线为板载 ESP32-C6 + ESP-Hosted / esp_wifi_remote。
- 明确当前只实现 2.4 GHz 路由器连接，不做 AP/host。
- 实现左侧可滚动 WiFi 扫描列表。
- 实现右侧 SSID/IP/Gateway/DNS/Status 显示。
- 实现 SSID/Password 输入框、Connect、Disconnect。
- 实现独立软键盘页面。
- 实现 WiFi 联网后 SNTP 时间显示。
- 实现点击时间区域切换本地时间 / UTC。
- 修复软键盘 `CLEAR/BACK/SPACE` 被普通 `K_` 字符分支误处理的问题。
- 编译、烧写并启动验证。
