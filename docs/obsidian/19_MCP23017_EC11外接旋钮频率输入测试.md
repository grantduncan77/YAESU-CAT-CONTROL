# MCP23017 + EC11 外接旋钮频率输入测试记录

日期：2026-08-29

## 目标

本阶段目标是在 ESP32-P4 控制端上，通过 I2C 外接微雪 MCP23017 I/O 扩展模块，再接入 EC11 旋转编码器，先验证最小控制闭环：

- 旋转编码器改变当前频率输入值。
- 按下编码器按键确认，并通过现有 CAT 通信链路发送频率设置命令。
- 第二个旋转编码器改变 RF Power，步进为 1W。
- 修正主界面模式读写目标，使模式按钮不再总是落到 VFO-A。
- 暂不扩展到复杂菜单或多功能旋钮，先验证硬件读取、去抖、方向判断、UI 输入刷新、CAT 发送是否可靠。

## 接线定义

用户提供的 EC11 接口定义图：

![[assets/mcp23017_ec11_wiring.png]]

频率输入旋钮接线：

| EC11 引脚 | MCP23017 引脚 | 功能 |
| --- | --- | --- |
| V | 3.3V | 电源正 |
| G | GND | 地 |
| A | PA0 | 编码器 A 相 |
| B | PA1 | 编码器 B 相 |
| S | PA2 | 编码器按键信号 |

功率旋钮接线：

| EC11 引脚 | MCP23017 引脚 | 功能 |
| --- | --- | --- |
| V | 3.3V | 电源正 |
| G | GND | 地 |
| A | PA6 | 编码器 A 相 |
| B | PA7 | 编码器 B 相 |
| S | PB0 | 编码器按键信号，当前仅完成读取/去抖预留 |

ESP32-P4 与 MCP23017 使用开发板 BSP 已初始化的 I2C 总线。当前 BSP 定义中 I2C 为：

- SDA：GPIO7
- SCL：GPIO8
- I2C 控制器：`CONFIG_BSP_I2C_NUM`

MCP23017 地址处理：

- 微雪资料显示 MCP23017 I/O Expansion Board 默认地址为 `0x27`，可通过 A0/A1/A2 跳线调整。
- 固件实现扫描 `0x20` 到 `0x27`，因此即使地址跳线变化，也能自动发现。
- 本次实机日志检测到地址：`0x27`。

## 固件实现

修改位置：

- `D:\CAT CONTROL\ft710_controller\components\app_controller\app_controller.c`
- `D:\CAT CONTROL\ft710_controller\components\app_controller\CMakeLists.txt`

新增依赖：

- `esp_driver_i2c`

新增核心逻辑：

- MCP23017 初始化：
  - 复用 BSP I2C。
  - 扫描 `0x20` 到 `0x27`。
  - 读取并写回 `IODIRA`，确保 PA0/PA1/PA2 为输入。
  - 读取并写回 `GPPUA`，打开 PA0/PA1/PA2 内部上拉。
  - 读取 `GPIOA` 作为编码器状态来源。

- EC11 解码：
  - 轮询周期：3 ms。
  - 频率旋钮 PA0/PA1 与功率旋钮 PA6/PA7 均使用四相查表解码。
  - 4 个有效跳变累计为 1 个旋钮档位。
  - 频率旋钮每档步进：`1000 Hz`。
  - 功率旋钮每档步进：`1 W`。
  - 当前输入框为空时，旋钮从当前目标 VFO 的实际频率开始递增/递减。
  - 当前输入框已有数值时，旋钮继续调整该输入值。
  - 功率旋钮直接更新本地功率显示，并通过命令队列发送 `PCxxx;`。
  - 功率上下限在固件中夹到 `5W` 到 `100W`。

- 按键处理：
  - PA2 低电平表示按下。
  - PB0 低电平表示第二旋钮按下，当前只完成读取和去抖，暂未绑定业务动作。
  - 去抖时间：35 ms。
  - 频率旋钮按下后调用统一的 `submit_input_frequency()`。
  - `submit_input_frequency()` 会解析输入频率，并通过已有命令队列发送 `CMD_SET_FREQ`。
  - 实际 CAT 发送仍走原有 CAT 任务，保持触摸按钮与外接旋钮一致。

- UI 刷新优化：
  - 旋钮旋转时只刷新输入提示区域，不整页刷新。
  - 这样减少了与 CAT 轮询 UI 更新之间的 LVGL 锁竞争。
  - 按键确认后同样只刷新输入提示区域。

- 模式目标修正：
  - 历史实测已确认 `MD02;` 可设置 VFO-A USB，`MD12;` 可设置 VFO-B USB。
  - 主界面此前模式面板主要跟随 `active_vfo`，实际使用中容易表现为只读/只改 VFO-A。
  - 本次改为模式按钮跟随频率输入目标 `A/B`：
    - 选择 `A` 时，模式面板读取/高亮/写入 VFO-A 模式，发送 `MD0x;`。
    - 选择 `B` 时，模式面板读取/高亮/写入 VFO-B 模式，发送 `MD1x;`。
  - `MD0;` 与 `MD1;` 慢轮询仍保留，分别更新 `mode_a` 和 `mode_b`。

## 当前结论

本次外接旋钮试验已经打通：

- ESP32-P4 能通过 I2C 识别 MCP23017。
- MCP23017 地址自动扫描有效，实机为 `0x27`。
- EC11 A/B/S 接 PA0/PA1/PA2 的读取逻辑已实现。
- 第二个 EC11 A/B/S 接 PA6/PA7/PB0 的读取逻辑已实现。
- 旋钮可以改变频率输入值。
- 按键确认后可以通过现有 CAT 链路发送 `FA...;` 频率设置命令。
- 第二旋钮可以按 1W 步进发送 `PCxxx;` 功率设置命令。
- 模式按钮已改为跟随输入目标 VFO，选择 B 后将发送 `MD1x;`，解决只能改 VFO-A 的问题。
- 旋钮 UI 刷新已从整页刷新优化为局部刷新，降低界面锁竞争。

## 遗留观察

监视日志仍出现 ESP-Hosted WiFi slave 连接失败：

```text
E transport: Not able to connect with ESP-Hosted slave device
```

这与本次旋钮功能不是同一条链路。当前旋钮测试依赖的是 ESP32-P4 主控、BSP I2C、MCP23017、CH9102 CAT 通信，不依赖 ESP-Hosted WiFi 成功连接。后续若继续处理 WiFi，需要单独清理 ESP-Hosted 配置、硬件连接和与 I2C/SPI 引脚的关系。

## 后续可调参数

- 如果旋钮方向与直觉相反：
  - 可交换 EC11 A/B 接线。
  - 或在固件中调换 `encoder_adjust_input(1)` 与 `encoder_adjust_input(-1)`。

- 如果 1 kHz 步进不合适：
  - 修改 `ENCODER_STEP_HZ`。
  - 可选值：`10 Hz`、`100 Hz`、`1000 Hz`、`10000 Hz`。

- 后续可扩展：
  - 频率旋钮短按确认、长按切换 VFO-A/VFO-B。
  - 功率旋钮按键可绑定功率步进、RF Power 面板聚焦或 TX 安全确认。
  - 按住旋钮旋转改变步进。
  - 加入旋钮状态栏图标或设置页。
  - 使用 MCP23017 中断引脚替代 3 ms 轮询，降低后台 I2C 访问频率。
