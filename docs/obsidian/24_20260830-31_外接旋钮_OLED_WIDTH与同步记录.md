## 硬件状态

本阶段使用的主要硬件：

- 主控：Waveshare ESP32-P4-WIFI6-Touch-LCD-7B
- 主控烧写/监视口：`COM4`
- 已确认芯片：ESP32-P4 rev v1.3
- 实测 MAC：`e8:f6:0a:e3:59:c6`
- I2C 主线：`SDA GPIO7`，`SCL GPIO8`
- 触摸：GT911，I2C 地址 `0x5D`
- I/O 扩展：MCP23017，实测地址 `0x27`
- I2C 复用器：TCA9548A，地址 `0x70`
- OLED：0.96 寸 SSD1306，地址 `0x3C`
- FT-710 CAT 当前可用路线：ESP32-P4 USB Host -> CH9102 USB-TTL -> FT-710 CAT-3

## 助手回复与处理过程摘要

### 功率旋钮步进选择

助手实现并验证：

- 功率旋钮按钮 `PB0` 按一次进入 RF Power 步进选择。
- 步进可选 `2W`、`5W`、`10W`。
- 初始步进为 `2W`。
- 再按一次退出步进选择，之后旋转按所选步进发送 `PCxxx;`。
- 进入步进选择后，0.96 OLED 显示 `RF STEP` 和当前步进。
- 退出步进选择后，OLED 回到 `RF POWER`。

关键验证日志：

```text
Power encoder enter step select, step=2W
Power encoder step select 5W
Power encoder step select 10W
Power encoder exit step select, step=10W
Power encoder set 42W step=10W
CAT set PC042; -> ESP_OK
```

### 双机 BLE / WiFi 串口透传尝试

助手按用户要求准备 DevKitC 与 P4 的 BLE 串口通信和 WiFi 透传：

- DevKitC 原计划作为 CAT-3 到 BLE/WiFi 的无线桥接端。
- DevKitC WiFi 目标 SSID：`KE`。
- P4 同样连接到 `KE`。
- DevKitC 侧拟使用 UART 接 CAT-3，再经 BLE/WiFi 转发到 P4。
- 用户提供 CAT-3 到 TXS0108E、再到 DevKitC 的线序：

```text
CAT-3 TXD -> TXS0108E B2 -> DevKitC GPIO17
CAT-3 RXD -> TXS0108E B1 -> DevKitC GPIO35
TXS0108E OE -> DevKitC GPIO32
```

阶段结论：

- DevKitC 当时出现故障，用户决定后面再试。
- 本阶段先把 P4 刷回最后一个可用版本，继续本地 I2C/OLED/旋钮功能。

### I2C 故障排查

用户反馈断开所有外接 I2C 后，P4 裸板复位后 GT911 触摸恢复。

处理过程：

- 判断外接 I2C 总线设备或线序会影响同一 I2C 总线上的触摸。
- 先只接 MCP23017 旋钮模块。
- 用户确认接旋钮模块后旋钮和触摸正常。
- 后续发现问题根因是线序接错。

### DNR 第三旋钮与 OLED

用户接入第三个旋钮控制 DNR：

```text
A -> PA3
B -> PA4
S -> PA5
OLED -> TCA9548A channel 4
```

助手实现：

- DNR 编码器读取 MCP23017 `PA3/PA4/PA5`。
- 旋转调整 DNR level。
- 按键按下直接关闭 DNR。
- DNR OLED 显示 `DNR` 和当前值；DNR 关闭时显示 `OFF`。
- 后续按用户要求去掉左下角 `FT-710` 字样。

### WIDTH 第四旋钮与 OLED

用户接入第四个旋钮控制 WIDTH：

```text
A -> PB7
B -> PB6
S -> PB5
OLED -> TCA9548A channel 2
```

助手实现：

- 新增 `CMD_SET_WIDTH`。
- 轮询加入 `SH0;`。
- 解析 `SH00xx;` 到 `s_state.width_index`。
- 旋转 WIDTH 旋钮调整索引 `00-23`。
- 按键将 WIDTH 设为 default，即发送 `SH0000;`。
- WIDTH 状态写入 `radio_state_t.width_index`。

关键 CAT 命令：

```text
读取 WIDTH: SH0;
设置 WIDTH: SH00xx;
恢复 default: SH0000;
```

### WIDTH OLED 画法修正

用户多次明确 WIDTH OLED 的目标画法。

最终版：

- 保留第一版梯形外轮廓的变化方式。
- 梯形上底和下底都随 WIDTH 数值变化。
- 下底原本的可变线段仍作为梯形外轮廓。
- 在同一条 y 坐标上将下底额外向左右延伸到屏幕边缘，成为贯穿屏幕的基准线。
- 梯形内部做交叉斜线填充。
- 整个梯形向屏幕顶端移动。
- WIDTH 对应的查表数值显示在基准线下方。
- 最后一轮将数值字体从 `1x` 放大到 `2x`。

实测日志显示 WIDTH 旋钮有效：

```text
Width encoder set 01
Width encoder set 02
...
Width encoder set 23
Width encoder set 22
...
Width encoder set 06
```

### RF Power OLED 修正

用户要求：

- 功率 OLED 上的功率数字变小。
- 功率数字上移一点。
- 左下角 `FT-710` 字符去掉。
- 最下面做一个类似进度条的功率显示范围，从 `5W` 到 `100W`。

助手实现：

- 将功率 OLED 从通用状态屏绘制函数拆出。
- 保留标题 `RF POWER`。
- 功率值用 `4x` 字号显示并上移。
- 删除左下角 `FT-710`。
- 底部绘制功率条，范围 `5-100W`。
- 功率小于 `5W` 按 `5W` 显示条，超过 `100W` 按 `100W` 封顶。

### DNR OLED 修正

用户要求：

- DNR OLED 也去掉左下角 `FT-710` 字符。

助手实现：

- 从通用状态屏函数中移除 `FT-710` 字样。
- DNR 和 RF STEP 继承该修改。
