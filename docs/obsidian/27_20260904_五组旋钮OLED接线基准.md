## 与上一版的关键变化

- 功率旋钮按键从 `PB0` 改为 `PB1`。
- 新增第 5 个旋钮：`A=PB4`、`B=PB3`、`S=PB2`。
- OLED 从 3 块扩展为 5 块。
- OLED 通道不再按功能直接描述，而是先按屏号描述：
  - 屏 1：channel 3
  - 屏 2：channel 2
  - 屏 3：channel 4
  - 屏 4：channel 5
  - 屏 5：channel 6

## 当前代码中的临时功能绑定

在正式做配置界面之前，主程序采用以下默认绑定：

| 组 | 当前默认功能 |
|---|---|
| 组 1 | 频率输入/频率小屏显示 |
| 组 2 | DNR 调节与 DNR 小屏显示 |
| 组 3 | RF Power 调节与功率小屏显示 |
| 组 4 | WIDTH 调节与 WIDTH 小屏显示 |
| 组 5 | 预留槽位，旋转时 OLED 数字递增/递减，按键清零，同时打印日志 |

这与后续目标一致：每个“旋钮 + OLED”组都可以在主控配置界面中选择不同功能。

## 功能抽象更新

用户进一步要求：按照前面设计框架，功能要抽象出来。

本次在不大拆文件、不破坏现有主程序结构的前提下，先完成了一个中间层抽象：

- 新增 `mcp_port_t`：描述 MCP23017 的 A/B 两个端口。
- 新增 `mcp_pin_t`：描述一个 MCP23017 引脚，由端口和 bit 组成。
- 新增 `control_function_t`：描述槽位功能类型。
- 新增 `control_slot_t`：描述一个“旋钮 + OLED”硬件/功能槽。

当前功能枚举：

```c
typedef enum {
    CONTROL_FN_FREQUENCY,
    CONTROL_FN_DNR,
    CONTROL_FN_POWER,
    CONTROL_FN_WIDTH,
    CONTROL_FN_SLOT_TEST,
} control_function_t;
```

当前 5 组槽位由 `s_control_slots[]` 统一描述：

```c
static control_slot_t s_control_slots[] = {
    group1 -> CONTROL_FN_FREQUENCY -> OLED1/channel 3
    group2 -> CONTROL_FN_DNR       -> OLED2/channel 2
    group3 -> CONTROL_FN_POWER     -> OLED3/channel 4
    group4 -> CONTROL_FN_WIDTH     -> OLED4/channel 5
    group5 -> CONTROL_FN_SLOT_TEST -> OLED5/channel 6
};
```

抽象后的关键变化：

- MCP23017 输入掩码不再手写固定功能 mask，而是由 `control_slot_collect_masks()` 从 `s_control_slots[]` 自动计算。
- OLED 初始化不再逐个写死 `s_width_oled/s_power_oled/s_dnr_oled`，而是循环遍历 `s_control_slots[]`。
- 旋钮任务不再维护 `prev_freq_ab/prev_power_ab/...` 等多套变量，而是每个 `control_slot_t` 自带：
  - `prev_ab`
  - `quad_accum`
  - `stable_button`
  - `last_button_sample`
  - `last_button_change`
- 旋转动作统一进入 `control_function_rotate()`。
- 按键动作统一进入 `control_function_press()`。
- 第 5 组目前作为 `CONTROL_FN_SLOT_TEST`，用于验证“可配置槽位”的基本输入和显示闭环。

这样后续要做主控配置界面时，只需要把 `control_slot_t.function` 从固定初始化改为从配置读取。例如：

```c
group1.function = CONTROL_FN_FREQUENCY;
group2.function = CONTROL_FN_POWER;
group3.function = CONTROL_FN_WIDTH;
group4.function = CONTROL_FN_DNR;
group5.function = CONTROL_FN_SLOT_TEST;
```

再往后可以把每个功能拆成独立模块，例如：

- `feature_frequency`
- `feature_power`
- `feature_dnr`
- `feature_width`
- `feature_swr_sweep`
- `feature_memory_channel`

每个功能模块提供统一接口：

```c
rotate(delta)
press()
render_oled(oled)
render_main_panel(panel)
```

本次完成的是第一阶段：在现有主程序里建立 slot/function 分层，让后续拆模块和菜单配置有明确落点。
