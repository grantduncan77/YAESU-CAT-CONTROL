# MENU 配置页与八项可配置功能实现

## 用户要求

用户提出：

- 菜单中加上一个配置旋钮功能的页面。
- 之前主屏右侧四个功能区域也应可以配置。
- 配置页面需要同时配置：
  - 5 组旋钮 + OLED 功能。
  - 主控屏幕上四个功能区域。
- 现阶段已有功能：
  - WIDTH
  - RF POWER
  - DNR LEVEL
  - BAND
  - MODE
- 本轮先再实现：
  - Noise Blanker
  - Notch
  - Mic Gain
- 这样形成 8 个功能，可以在中控屏和/或旋钮 + OLED 上配置。
- 用户随后补充：UI 右上角已经有 `MENU` 字样显示。

## 本轮设计决策

右上角已有 `MENU` 文本，因此不再额外绘制第二个菜单按钮，而是在现有 `MENU` 字样区域增加触摸热区。

点击主界面右上角 `MENU` 后进入配置页。

配置页分为两个区域：

- `KNOB + OLED SLOTS`
  - 配置 5 组外接旋钮 + OLED。
  - 每组显示 `GROUP n` 和当前绑定功能。
  - 点击对应组按钮，在当前 8 个可用功能中循环切换。
  - 切换后立即刷新对应 OLED 显示。

- `MAIN SCREEN PANELS`
  - 配置主屏右侧 4 个功能面板。
  - 每个面板显示 `PANEL n` 和当前绑定功能。
  - 点击对应面板按钮，在当前 8 个可用功能中循环切换。
  - 返回主界面后，右侧四个控制区域按配置重新绘制。

## 当前 8 个可配置功能

| 功能 | CAT 命令 | 主屏面板 | 旋钮 | OLED |
|---|---|---|---|---|
| WIDTH | `SH` | 支持 | 支持 | 支持 |
| RF POWER | `PC` | 支持 | 支持 | 支持 |
| DNR LEVEL | `RL/NR` | 支持 | 支持 | 支持 |
| BAND | `BS/FA/FB` | 支持 | 支持 | 支持 |
| MODE | `MD` | 支持 | 支持 | 支持 |
| Noise Blanker | `NB/NL` | 支持 | 支持 | 支持 |
| Notch | `BC/BP` | 支持 | 支持 | 支持 |
| Mic Gain | `MG` | 支持 | 支持 | 支持 |

说明：

- `BAND` 当前按项目既有设计写入常用波段默认频点。
- `MODE` 当前按项目既有设计切换当前输入/活动目标 VFO 的模式。
- `Noise Blanker` 使用 NB 开关与 NB Level 数值组合实现。
- `Notch` 当前按本地功能池中的 `BC Auto Notch / DNF` 与 `BP Manual Notch` 实现，后续仍需要在 FT-710 实机上确认 BP 参数范围和显示映射是否完全符合预期。

## 代码实现概要

核心文件：

`D:\CAT CONTROL\ft710_controller\components\app_controller\app_controller.c`

本轮主要改动：

- 新增 `SCREEN_CONFIG` 页面状态。
- 新增主屏 `MENU` 热区 `NAV_CONFIG`。
- 新增 `create_config_ui()` 配置页。
- 新增 `s_config_functions[]`，作为本阶段 8 个可选功能列表。
- 新增 `s_main_panel_functions[]`，保存主屏四个右侧功能面板当前绑定功能。
- 新增通用 `create_feature_panel()`，根据绑定功能绘制面板。
- 将主界面右侧原固定 RF POWER / DNR / MODE / BAND 改为四个可配置面板。
- 扩展 `control_function_rotate()` 和 `control_function_press()`：
  - 旋钮按绑定功能分发到对应子功能。
  - `DNR LEVEL` 已作为单独可配置项接入旋钮和按键。
  - `BAND`、`MODE`、`Noise Blanker`、`Notch`、`Mic Gain` 已接入旋钮逻辑。
- 扩展辅助 OLED 显示：
  - `aux_oled_show_current()` 不再固定刷新某几个功能。
  - 改为按 `control_slot_t` 的当前绑定功能生成 OLED 标题和值。
- 扩展 `s_feature_catalog[]`：
  - 将 `Noise Blanker`、`Manual Notch`、`Mic Gain` 标记为当前可实现功能。

## 新增 CAT 写入

Noise Blanker：

- 关闭：`NB00;`
- 打开：`NB01;`
- 设置等级：`NL0xx;`，当前按本地项目资料限制为 `00-10`
- 当等级大于 0 时，先写等级，再打开 NB。

Notch：

- 关闭：`BC00;`
- 打开：`BC01;`
- 设置值：`BP0xx;`，当前代码限制为 `00-99`
- 当值大于 0 时，先写 BP，再打开 BC。

Mic Gain：

- 设置：`MGxxx;`
- 当前代码限制为 `000-100`

## 新增 CAT 轮询读取

慢轮询中追加：

- `NB0;`
- `NL0;`
- `BC0;`
- `BP0;`
- `MG;`

读回结果写入 `radio_state_t`：

- `noise_blanker_on`
- `noise_blanker_level`
- `notch_on`
- `notch_value`
- `mic_gain`

## 注意事项

本轮是框架和功能接入实现，尚未完成实机全功能验证。

需要重点实测：

- `NB/NL` 在 FT-710 上的等级范围和响应速度。
- `BC/BP` 是否与用户期望的 Notch 控制完全一致。
- `MG` 设置后是否与 FT-710 菜单中的 Mic Gain 显示同步。
- 主屏配置页切换后，四个面板是否符合触摸面积和文字尺寸要求。
- 五组旋钮/OLED 在不同功能之间切换后，是否都能立即刷新并正确发送 CAT。

## 2026-09-05 配置页交互改为轮盘选择

用户要求：

- 配置界面默认按钮均为灰色。
- 点击某个旋钮/OLED 组或主屏功能区域后，该按钮亮起。
- 弹出所有可选功能的选择窗口。
- 选择内容需要能上下滑动。
- 选定后必须确认，配置才生效。
- 随后补充希望选择界面做成“轮盘样式”，视觉更新鲜一些。

实现结果：

- 保留配置页两个配置范围：
  - 上半部分：5 组 `旋钮 + OLED`。
  - 下半部分：主界面右侧 4 个可配置功能面板。
- 新增配置页临时选择状态：
  - `CONFIG_TARGET_NONE`
  - `CONFIG_TARGET_SLOT`
  - `CONFIG_TARGET_PANEL`
  - `s_config_target_index`
  - `s_config_pending_function`
- 进入 `MENU` 配置页时先重置选择状态，因此所有配置按钮默认显示灰色。
- 点击 `GROUP n` 或 `PANEL n` 时：
  - 只记录当前配置目标。
  - 当前目标按钮变为青色高亮。
  - 不立即改变功能配置。
- 弹窗使用 LVGL `lv_roller` 实现轮盘式功能选择：
  - 中间选中项使用青色高亮。
  - 上下滑动轮盘选择 `WIDTH / RF PWR / DNR LVL / BAND / MODE / NB / NTCH / MIC LVL`。
  - 轮盘滚动只改变待确认功能，不立即生效。
- 弹窗底部提供：
  - `CANCEL`：取消本次选择并回到灰色默认状态。
  - `APPLY`：确认并写入配置。
- 对 `旋钮 + OLED` 组按 `APPLY` 时调用 `control_slot_set_function()`：
  - 更新该组旋钮功能。
  - 立即失效并刷新对应组的 OLED。
- 对主屏功能面板按 `APPLY` 时更新 `s_main_panel_functions[]`，回主界面后对应功能区按新绑定绘制。
